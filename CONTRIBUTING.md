# Contributing

1. Claim an Issue before starting work.
2. Create a short-lived branch from `main` for one task.
3. Make a focused change and use a clear commit message (`docs:`, `test:`, `chore:`, `fix:`).
4. Open a Pull Request and link the Issue.
5. Ask a second member to review.
6. Redact sensitive data before requesting review.
7. Merge only after review and update the Project board.

Team agreement: do not push directly to `main`. Never commit raw Burp projects, HAR/HTTP captures, credentials, tokens, cookies, API keys, private keys, or unredacted personal data.
