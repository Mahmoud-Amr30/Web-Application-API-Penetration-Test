# Security and Sensitive Data Handling

This is a private educational security-assessment repository. The target is an intentionally vulnerable DVWA lab and must remain local/loopback-only.

Never commit credentials, cookies, session tokens, API keys, private keys, raw Burp projects, unredacted HAR/HTTP captures, or personal data. If a secret is exposed, notify the team, revoke/rotate it where applicable, and follow the agreed cleanup process. Deleting it in a later commit does not remove it from Git history.

Do not scan or test systems outside the approved local lab and written scope.
