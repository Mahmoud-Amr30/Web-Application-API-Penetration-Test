 Project Overview
This repository contains the methodology, custom tools, assessment checklists, and security reports for evaluating the security posture of target Web Applications and REST APIs.

 Scope & Coverage
Web Security: OWASP Top 10 (SQLi, XSS, CSRF, IDOR, SSRF, etc.)
API Security: OWASP API Security Top 10 (BOLA, Broken Auth, Mass Assignment, Rate Limiting, etc.)

 Tools & Technologies
Proxy & Interception: Burp Suite Professional / OWASP ZAP
API Testing: Postman, Bruno, Hoppscotch
Automated Scanning & Recon: Nmap, Nuclei,ffuf, Gobuster, SQLmap
Scripting: Python 3, Bash
