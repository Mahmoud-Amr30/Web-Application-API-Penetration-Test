# Web Application & API Penetration Testing

## 📌 Project Overview

This repository contains the methodology, custom tools, assessment checklists, and security reports developed to evaluate the security posture of target **Web Applications** and **REST APIs**.

The project focuses on identifying, analyzing, and documenting security vulnerabilities through structured penetration testing activities.

## 🎯 Scope & Coverage

### 1. Web Application Security

Assessment based on the **OWASP Top 10**, covering vulnerabilities such as:

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Insecure Direct Object References (IDOR)
- Server-Side Request Forgery (SSRF)
- Other common web application security vulnerabilities

### 2. API Security

Assessment based on the **OWASP API Security Top 10**, covering vulnerabilities such as:

- Broken Object Level Authorization (BOLA)
- Broken Authentication
- Mass Assignment
- Unrestricted Resource Consumption / Rate Limiting
- Other common API security vulnerabilities
